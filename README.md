# Generating Data Sets Using Social Media API's
Using Youtube V3 RESTful API to generate a dataset (deprecated files folder)

The goal of this project is to perform EDA and sentiment/emotional analysis on several public figures across different social media platforms...
Specifically looking at 10 different media outlets and their coverage of them.
Both a list of the people of intrest and media outlets can be found in Query_Builder.py *(should be renamed to a more fitting file name)*
